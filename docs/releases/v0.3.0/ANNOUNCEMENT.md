## Product boundaries

X-Ray covers selected decoded instructions; gray steps are not assessed. It follows recorded instruction order rather than real timing. Token instruction amounts are not guaranteed net receipts. Final net balances are separate; intermediate balances are not simulated. Historical findings do not certify current permissions, program reputation, future safety or settlement. 257 unit tests and 16 browser tests are automated validation, not an independent audit. The 0.3.0 release remains a pre-release.
